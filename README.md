2027赛季半舵步兵云台

## 底盘云台职责划分

#### 1. 底盘

接收发送指令（enabled,vx,vy,w,yaw），完成运动，反馈状态（vx,vy,w,姿态）。
底盘自己从共享 CAN1 读取 yaw 电机（RS05）反馈，扣与云台相同的机械偏置得到实测相对角 θ；
帧里的 yaw 是**目标偏角** θ_ref：normal/hole 为 0，gyro 按自转速度斜坡变化。
跟随律 w = w_ff + PID(wrap(θ − θ_ref))，其中 w 字段只带云台侧的速度前馈/定值自转，
PID 在底盘侧用自己读到的实测 θ 计算（见 app_chassis_force.c 的 ChassisWCommand）。

#### 2. 云台

## 操作逻辑（按照模式分类）

**遥控器上侧4个拨动开关，检索分别为4,5,6,7，从上到下分别0,1,2（2段开关只有0,1）**

#### 1. 失能，停止

1. 操作：Switch_4=0
2. 反应：全部电机失能

#### 2. 普通模式（normal）

1. 操作：(Switch_4=1)&&(Switch_6=0)
2. 反应：云台直立，底盘前进方向为云台指向，底盘w随yaw转动（相对位置几乎不变，只有yaw转动时有小差值）

#### 3. 小陀螺模式（gyro）

1. 操作：(Switch_4=1)&&(Switch_6=1)
2. 反应：云台直立，底盘前进方向为云台指向，底盘w为定值/变速

#### 4. 过洞模式（hole）

1. 操作：(Switch_4=1)&&(Switch_6=2)
2. 反应：云台先等 yaw 轴与底盘前进方向对正（底盘跟随把相对角拉回 0），随后下 pitch 以速度闭环驶向倒下位、上 pitch 折叠到 0；倒下后下 pitch 输出 0（关闭重力前馈），yaw 仍可控制。

#### 5. 自瞄模式（visual）

1. 操作：(Switch_4=1)&&(Switch_7=1)&&(vision_recv_data.appear=1)
2. 反应：云台交给视觉控制，底盘前进方向为云台指向，底盘w随yaw转动（相对位置几乎不变，只有yaw转动时有小差值）
